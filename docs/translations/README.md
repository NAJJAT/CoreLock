# Translation reviews

CoreLock is in English, Arabic, French and Dutch. The Arabic, French and Dutch texts are
machine translations until a native speaker has checked them: Arabic by the owner, French
and Dutch by native speakers (CLAUDE.md §8). Each file lists the strings added or changed
in one version, with the English next to each translation.

| File | Strings from | Review |
|---|---|---|
| [TRANSLATION_REVIEW_1.3.md](TRANSLATION_REVIEW_1.3.md) | The 1.3 work (1.3.0, in preparation) | Not recorded as done |

The reviews for 1.0, 1.1 and 1.2 are in
[archive/translations/](../archive/translations/). None of them is recorded as done
either, so their strings may still need a native speaker; the archive README lists them.
When a review is done, write it at the top of its file (who, which languages, the date).

To correct a translation, edit the string file named in the section
(`app/src/main/res/values-ar/`, `values-fr/`, `values-nl/`), not the table: the tables
are copies of those files.
